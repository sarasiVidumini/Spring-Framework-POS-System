# SpringBoot POS System

A simple Point of Sale (POS) system built with a **Spring Boot backend** and a **web-based frontend**.

> Repo Structure:
- `Backend/` – Spring Boot REST API (Java)
- `Frontend/` – Web UI (HTML/CSS/JavaScript)  (likely AJAX-based)

## Features
- Customer management (CRUD)
- Item / Product management (CRUD)
- Order management (place orders, view order details)
- REST API based backend + separate frontend UI

> ✅ Note: If your exact modules differ (e.g., Users/Auth, Reports), update this section accordingly.

## Tech Stack
### Backend
- Java + Spring Boot
- Spring Web (REST)
- Spring Data JPA / Hibernate
- MySQL (or your configured DB)
- Maven

### Frontend
- HTML
- CSS
- JavaScript (AJAX)
